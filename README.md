## 🧩 여행을 특별하게 기록하는 방법 ‘여행조각’

> 여행은 특별한 경험을 선사하지만, 소중한 순간들을 기억하고 공유하는 것은 쉽지 않습니다.
> <br/> '여행조각'은 사진, 영상, 글, 음악 등 다양한 형태의 기록을 하나의 플랫폼에서 관리하고, 여행의 감동을 더욱 풍부하게 만들어줍니다.
